# 紹介文の下書き（そのまま使える形）

- `x-posts.md` … X の投稿。日本語 8 本・英語 4 本。文字数は計算済み（上限 280）。コードブロックの中身をそのまま貼る。
- `zenn/*.md` … Zenn の記事 5 本。見出し情報つき（`published: false`）。Zenn に貼って、確認してから公開にする。末尾に元の記事へのリンクがある。Qiita に出すときは、見出し情報だけ Qiita の形式に直す。
