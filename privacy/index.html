あつかい

預かるもの、預からないもの。
最終更新 2026年10月

預かるもの

番付（ランキング）に載せたときだけ、入れた名前・得点を、こちらのサーバーに預かります。作品によって、これに少し足したものを預かります。

「すし積む」では端末が作った番号とその一戦の手順も預かります。手順は、得点の辻褄を見るためのものです。「端末が作った番号」は、その端末の中でランダムに作られる文字列で、同じ人の記録をまとめるためだけに使います。誰かを特定するものではありません。

「10秒ピッタリで止めろ！」では、名前と3回ぶんの誤差、載せた時刻だけです。端末の番号は作りません。その日ぶんの順位は日付が変わると流れます。

「寝返り将棋」では、オンライン対戦を遊んだとき（と順位表を開いたとき）に、端末が作った番号、名前（既定は「名無し」）、レーティング、勝ち負けの数、一局ごとの手順と結果を預かります。順位表に、名前とレーティングが載ります。AI 対戦と、同じ端末での2人対戦では、何も預かりません。

名前は自由に決められます。本名を入れる必要はありません。

預からないもの

それ以外は何も集めません。会員登録も、個人を追いかける仕組みも入っていません。広告はまだ表示していません（下の「広告について」を読んでください）。メールアドレスも、電話番号も、位置情報も、一切受け取っていません。

ただし、このサイトを置いている Cloudflare の、アクセスの集計（Cloudflare Web Analytics）が動いています。ページが何回開かれたか、どのページがよく読まれているか、といった数を数えるためのもので、個人を追いかけたり、広告に使ったりはしていません。

端末の中だけに残るもの

ハイスコア・自己ベスト・寿司図鑑・言葉の設定・音の設定は、その端末の中にだけ残ります。番付に載せなければ、外へは何も出ません。ブラウザの保存領域を消せば、いつでも消えます。

記事のコメント欄

記事の終わりに、コメント欄を置く場合があります。「コメントを開く」を押したときだけ、コメントの仕組み（giscus。giscus.app）と GitHub に接続します。押さなければ、接続しません。

コメントを書くには、GitHub のアカウントが要ります。書いたコメントは、GitHub の Discussions（このサイトのリポジトリ）に保存されて、誰でも読めます。名前（GitHub のユーザー名）も、一緒に表示されます。消したいときは、GitHub 上で、ご自身で削除できます。

預けたものを消したいとき

番付に載せた記録を消したい場合は、載せた名前を添えて、About にある連絡先までご連絡ください。確認のうえ削除します。

置き場所

このサイトと番付のサーバーは Cloudflare 上で動いています。番付のデータは、「すし積む」は Cloudflare の D1（データベース）に、「10秒ピッタリで止めろ！」は Cloudflare の KV に保存されます。

広告について

ゲームを他のサイト（ゲームポータル）に出しているときは、そのサイトの広告の仕組みが働くことがあります。その場合は、それぞれのサイトの方針に従います。このサイトでは、Google AdSense の審査のために、Google の広告用スクリプトを読み込んでいます。審査を通るまで広告は表示しません。広告を表示するようになったときは、使う仕組み（Cookie など）とその止め方を、ここに追記します。

子どもについて

年齢を尋ねていませんし、年齢に関わる情報も集めていません。番付に名前を載せる以外に、こちらへ届くものはありません。
