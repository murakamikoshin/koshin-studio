預かるもの、預からないもの。
最終更新 2026年10月

預かるもの

番付（ランキング）に載せたときだけ、入れた名前・得点を、こちらのサーバーに預かります。作品によって、これに少し足したものを預かります。

「すし積む」では端末が作った番号とその一戦の手順も預かります。手順は、得点の辻褄を見るためのものです。「端末が作った番号」は、その端末の中でランダムに作られる文字列で、同じ人の記録をまとめるためだけに使います。誰かを特定するものではありません。

「10秒ピッタリで止めろ！」では、名前と3回ぶんの誤差、載せた時刻だけです。端末の番号は作りません。その日ぶんの順位は日付が変わると流れます。

「寝返り将棋」では、オンライン対戦を遊んだとき（と順位表を開いたとき）に、端末が作った番号、名前（既定は「名無し」）、レーティング、勝ち負けの数、一局ごとの手順と結果を預かります。順位表に、名前とレーティングが載ります。AI 対戦と、同じ端末での2人対戦では、何も預かりません。

「ドラフト会議ごっこ」では、部屋の中でのやり取りのために、端末が作った番号、球団名、育てた選手の名前、指名した選手（または選択肢）、チャットの発言、通報、部屋の設定を、その部屋のあいだだけ預かります。自分の画像をアイコンにした場合は、端末で小さくした画像が、その部屋の参加者にだけ送られます（ランダムマッチと公開中の部屋では、広告のあるロビーと結果の画面には出さず、エンブレムを表示します）。不適切な画像は、2人の通報で全員から隠れます。ホストが選手の名前や能力を登録した場合は、その内容も同じ部屋の中だけで扱います。ランキングはありません。部屋のデータは、ゲーム終了の10分後（誰もいなくなった部屋は30分後）に、通報の記録もふくめてすべて削除されます。スタンプと定型文は保存しません。

「ドラフト会議ごっこ」で育てた選手を、あなたが「世界に公開する」に設定した場合に限り、その選手の名前・ポジション・能力・実績を、30日間（最新1000人まで）サーバーに保存し、ほかの人の部屋の候補に「世界の選手」として表示します。球団名・端末が作った番号など、あなたを特定できる情報は一緒に保存しません。不適切な選手は、利用者2人の通報で保存から削除されます。公開した選手が指名された回数などは、数字だけを保存します。

チャットや名前など、ほかの参加者が入力した内容は、同じ部屋の人に表示されます。ホストが実在の人物の名前などを登録する場合、その内容はホストの責任です。不適切な内容は、自動で弾き、通報（2人で全員の画面から非表示）できる仕組みを用意しています。

名前は自由に決められます。本名を入れる必要はありません。

預からないもの

それ以外は何も集めません。会員登録も、個人を追いかける仕組みも入っていません。広告を表示することがあります（下の「広告について」を読んでください）。メールアドレスも、電話番号も、位置情報も、一切受け取っていません。

ただし、このサイトを置いている Cloudflare の、アクセスの集計（Cloudflare Web Analytics）が動いています。ページが何回開かれたか、どのページがよく読まれているか、といった数を数えるためのもので、個人を追いかけたり、広告に使ったりはしていません。

端末の中だけに残るもの

ハイスコア・自己ベスト・寿司図鑑・言葉の設定・音の設定、「ドラフト会議ごっこ」の球団名・アイコン・端末の番号（再入室用）・前回の選択は、その端末の中にだけ残ります。番付に載せなければ、外へは何も出ません。ブラウザの保存領域を消せば、いつでも消えます。

記事のコメント欄

記事の終わりに、コメント欄を置く場合があります。「コメントを開く」を押したときだけ、コメントの仕組み（giscus。giscus.app）と GitHub に接続します。押さなければ、接続しません。

コメントを書くには、GitHub のアカウントが要ります。書いたコメントは、GitHub の Discussions（このサイトのリポジトリ）に保存されて、誰でも読めます。名前（GitHub のユーザー名）も、一緒に表示されます。消したいときは、GitHub 上で、ご自身で削除できます。

預けたものを消したいとき

番付に載せた記録を消したい場合は、載せた名前を添えて、About にある連絡先までご連絡ください。確認のうえ削除します。

置き場所

このサイトと番付のサーバーは Cloudflare 上で動いています。番付のデータは、「すし積む」は Cloudflare の D1（データベース）に、「10秒ピッタリで止めろ！」は Cloudflare の KV に保存されます。「ドラフト会議ごっこ」の部屋のデータは、Cloudflare の Durable Objects に、上に書いた期間だけ保存されます。

広告について

ゲームを他のサイト（ゲームポータル）に出しているときは、そのサイトの広告の仕組みが働くことがあります。その場合は、それぞれのサイトの方針に従います。

このサイトは、Google AdSense で広告を表示します。Google を含む第三者配信事業者は、Cookie などを使って、このサイトや他のサイトへの過去のアクセス情報に基づいて広告を配信することがあります。表示される広告の内容やその仕組みは、Google の広告に関するポリシーに説明があります。

パーソナライズ広告は、Google の広告設定でいつでも無効にできます。第三者配信事業者の Cookie は、aboutads.info からも無効にできます。欧州経済領域（EEA）・英国からのアクセスでは、Google が用意する同意の画面が先に出ます。広告に使うこと以外の目的で、こちらが Cookie の情報を受け取ることはありません。

子どもについて

年齢を尋ねていませんし、年齢に関わる情報も集めていません。番付に名前を載せる以外に、また「ドラフト会議ごっこ」の部屋の中で入力した内容（チャットなど）を除いて、こちらへ届くものはありません。
