テーマ別に読む

本数が多いので、はじめての方は、次のテーマから選ぶと読みやすいです。

データを集めて、照合する

トレカの抽選情報を、巡回で集め、店と商品に結びつける。取りこぼしと取り違え、エラーを出さずに壊れていたことの記録。

  • 巡回と監視の取りこぼしを減らした7つの記録：ページ送り・X 監視・カバー率の測り方・先着の順番待ち
  • 店名の照合で起きた4つの取り違え：表記ゆれ・あいまいな地図検索・「同じ応募ページ＝同じ店」・1ページ複数案件
  • 商品名の照合で起きた8つの失敗：英語とカタカナ、セット商品の分け方、公式カタログ、誤字の増殖
  • エラーを出さずに壊れていた7つの事例：本物の抽選を捨てる・読めていない・失敗を握りつぶす

運用と費用

毎日動く処理とサーバー、AI とデータベースの費用、データの直し方。動き続ける仕組みを、測って直した記録。

  • 定期実行とサーバー運用で起きた9つのこと：タイムアウト・時間予算・配備のたびの再実行・VPS 移行
  • AI と Firestore の費用を、測り直して削った5つの記録：Gemini の計器・読み取りの91%・取得の費用
  • データの不具合を直すときの7つの教訓：すでにあるデータ・一括処理の事故・重複の数え方・通知の関門

iOS アプリと App Store

審査、ビルド、固まる・落ちる・反応しない。iPhone アプリで実際に起きたことの記録。

  • App Store 審査で止まったこと：はじめての提出の「Guideline 2.1 Information Needed」と、4つのリジェクト
  • ITMS-91064「無効なバイナリ」：NSPrivacyTracking が true なのに NSPrivacyTrackingDomains が空だった
  • Xcode 15.2 で Firebase 12 が使えない（Swift 6.0 必須）：Firebase 11.4.0 と AdMob 11.5.0 に固定した理由
  • iOS アプリが固まって強制終了される（0x8BADF00D）：SwiftUI の計算プロパティが毎回走っていた
  • Firebase Auth：アプリを完全に終了すると、匿名アカウントが量産された（currentUser の復元待ち）

  • TestFlight にビルドが来ない：Xcode Cloud の月25時間を使い切っていた（最初の診断は誤りだった）
