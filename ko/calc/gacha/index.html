가챠 컴플리트 계산기

모든 종류를 모으려면 몇 번, 얼마가 들까?

종류 수와 이미 가진 수를 입력하세요. 평균 횟수, 90%의 사람이 다 모으는 횟수, 비용, 컴플리트 세트가 더 싼지를 알려 줍니다.

계산 방법

c종류를 가졌을 때, 1회에 새 종류가 나올 확률은 (n − c) / n입니다. 평균은 n × (1 + 1/2 + 1/3 + …). “90%의 사람” 횟수는 한 번씩 진행하며 완성 확률이 90%를 넘는 시점을 찾습니다. 5종류에서 20만 명을 시뮬레이션해도 같은 결과였습니다(평균 11.41, 절반 10회, 90% 18회, 99% 28회).

적용되지 않는 경우

  • 모든 종류가 같은 확률로 나온다고 가정합니다. 시크릿처럼 나오기 어려운 종류가 있으면 표시된 것보다 더 많이 뽑아야 합니다.
  • 캡슐 구성이 정해진 머신(중복이 적음)은 지원하지 않습니다.
  • 확률 계산일 뿐이며, 반드시 다 모을 수 있다는 뜻은 아닙니다.

하나만 원하거나 천장(N회째 확정)이 있다면 확률·천장 계산기를 쓰세요.
