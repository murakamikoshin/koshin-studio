Gacha completion calculator

How many pulls, and how much money, to collect every type?

Enter the number of types and how many you already own. You get the average number of pulls, the number of pulls within which 90% of people finish, the cost, and whether a complete set is cheaper.

How it works

If you own c types, one pull gives a new type with probability (n − c) / n. The average is n × (1 + 1/2 + 1/3 + …). The “90% of people” number is found by stepping one pull at a time until the chance of being done passes 90%. For 5 types, simulating 200,000 people gave the same numbers (average 11.41, half within 10, 90% within 18, 99% within 28).

When this does not apply

  • It assumes every pull gives each type with the same probability. If some types are rarer (like a secret), completing takes more pulls than shown.
  • Machines with a fixed set of capsules inside have fewer duplicates. They are not supported.
  • This is a probability calculation. It does not mean you will complete the collection.

For a single item or a pity (guaranteed after N pulls), use the drop rate and pity calculator.
