How to read a type code

A type code is one letter per axis for the side you leaned to. For example RDCP-VM (“Abyss-Gazing Theory Collector”) is made of these six letters:

AxisLetterSide
WorldRRealistic: You are moved by grounded human drama
AftertasteDDark: You remember stories most when there is no salvation
Structure & paceCForeshadowing: You love picking up foreshadowing and theorizing
Sub-tastePMind games: You like mind games and drama between the lines
Visual vs storyVVisuals: You get hooked by visuals and directing
Viewing styleMDeep-dive: You savor one episode at a time, then read every analysis

Each axis has two sides, so 26 = 64 types. How the quiz works is in how to choose an anime quiz, and what the axes mean is in the six axes.
